# AutoScale 5.2 — AI Auto Resolver LIGHT

Основа: стабильная AutoScale 5.1.

## Что нового
- AI Image Engine теперь загружается раньше основного приложения.
- Реестр использует точные `id` автомобилей из базы.
- После загрузки реестра сцена автоматически перерисовывается.
- При наличии изображения в registry оно показывается автоматически.
- При отсутствии или ошибке изображения сайт не ломается и использует SVG fallback.
- Архив LIGHT не содержит тяжёлых PNG/JPG/WebP изображений.

## Как добавить готовое изображение позже
1. Поместить файл, например:
   `assets/generated/side/honda-vezel-ru1-2015.webp`
2. В `data/image-registry.json` указать:
   `"side": "assets/generated/side/honda-vezel-ru1-2015.webp"`

Аналогично для `front`.

## Важно
GitHub Pages продолжает работать без backend и без платных API.
