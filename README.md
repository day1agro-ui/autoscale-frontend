# AutoScale 4.3 — Queue Compare

AutoScale сравнивает реальные габариты автомобилей в одном масштабе.

## Доступные ракурсы
- Сбоку: длина, высота и колёсная база
- Спереди: ширина и высота

Вид сверху полностью удалён из интерфейса, базы визуальных путей и проекта.

## Способы сравнения
- Друг над другом
- Друг за другом — автомобили размещаются последовательно в одной визуальной сцене с сохранением относительного масштаба.

## Что изменено в 4.3
- Удалён режим «Сверху».
- Удалены top-изображения из данных автомобилей.
- Удалён старый режим «Наложение».
- Добавлен режим «Друг за другом».
- Для бокового вида дополнительно отображается колёсная база.
- Обновлены подписи, статус и структура данных.
