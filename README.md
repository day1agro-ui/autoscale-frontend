# AutoScale 2.0

Готовая статическая версия AutoScale с отдельной базой автомобилей.

## Структура

- `index.html` — интерфейс
- `cars.json` — база автомобилей
- `assets/css/style.css` — стили
- `assets/js/app.js` — логика приложения
- `assets/silhouettes/` — папка для будущих SVG-силуэтов

## Что нового

- база вынесена из HTML в `cars.json`
- поиск автомобилей
- выбор первого и второго автомобиля
- случайное сравнение
- смена автомобилей местами
- визуальное сравнение в одном масштабе
- разница габаритов
- полная таблица характеристик
- ссылки на конкретную пару автомобилей
- кнопка поделиться

## Публикация на Render

1. Замените содержимое GitHub-репозитория файлами из архива.
2. В корне репозитория должны лежать `index.html` и `cars.json`.
3. Для Static Site:
   - Build Command: пусто
   - Publish Directory: `.`
4. Commit/push в ветку `main`.
5. Render автоматически обновит сайт.

Важно: для локального запуска `fetch("cars.json")` лучше открывать сайт через простой локальный сервер, а не двойным кликом по HTML.
