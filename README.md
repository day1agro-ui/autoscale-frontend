# AutoScale 3.0

Готовая статическая версия сайта для сравнения реальных габаритов автомобилей.

## Новая архитектура

```text
autoscale-v3.0/
├── index.html
├── README.md
├── data/
│   └── cars.json
└── assets/
    ├── css/
    │   └── style.css
    ├── js/
    │   ├── app.js
    │   ├── database.js
    │   └── renderer.js
    └── silhouettes/
        └── (будущие реальные SVG-силуэты)
```

## Что есть в 3.0

- отдельная база автомобилей `data/cars.json`;
- модульная JavaScript-архитектура;
- умный поиск по нескольким словам;
- выбор марки, модели, поколения и версии;
- два независимых слота сравнения;
- случайное сравнение;
- смена автомобилей местами;
- боковой и фронтальный режим визуализации;
- разница габаритов;
- наглядные шкалы;
- расширенная таблица характеристик;
- URL с выбранной парой;
- копирование и нативная отправка ссылки.

## Добавление автомобиля

Добавьте объект в `data/cars.json` по существующему шаблону. Интерфейс автоматически подхватит новую машину.

## Render

Для Static Site:

- Build Command: оставить пустым
- Publish Directory: `.`

После push в GitHub Render автоматически задеплоит обновление.
