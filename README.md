# AutoScale 4.2.3 — Dimension Axis Fix

Исправлена визуальная логика активных проекций.

## Проекции
- Сбоку: длина × высота
- Спереди: ширина × высота
- Сверху: длина × ширина

## Что исправлено
- В карточке автомобиля выводятся оба параметра активной проекции.
- Сравнение в статусе строится по главному параметру текущего вида.
- Дополнительно показывается разница по второму параметру.
- Сохранена полная рабочая структура версии 4.2.2.
- Сохранены реальные изображения и SVG fallback.
