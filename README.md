# AutoScale 4.3.1 — Visual Polish

Стабильная версия с двумя ракурсами (сбоку и спереди), режимами «Друг над другом» и «Друг за другом».

В 4.3.1 доработан режим «Друг за другом»: обе машины автоматически помещаются в одну сцену без горизонтальной прокрутки и обрезания изображений.


## Safe Grid Patch
Эта сборка создана от пользовательской рабочей версии AutoScale 4.3.1 Visual Polish LITE.
Изменён только `assets/css/style.css`.

Добавлена постоянная математическая сетка:
- 10 колонок = 5000 мм по горизонтали;
- 6 строк = 3000 мм по вертикали;
- одна ячейка = 500 × 500 мм.

JavaScript, HTML, база автомобилей и визуальная логика не изменялись.
