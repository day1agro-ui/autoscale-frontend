# AutoScale 4.2.2 — FULL CLEAN

Полная чистая структура проекта для GitHub/Render.

## Важно
Загружайте содержимое папки `AutoScale-4.2-FULL-CLEAN` в корень репозитория. Не смешивайте файлы со старыми версиями 4.0/4.1/4.2.

## Структура
- `index.html` — главная страница
- `data/cars.json` — база автомобилей
- `assets/js/app.js` — логика и резервная встроенная база
- `assets/js/visual-engine.js` — визуальный движок
- `assets/css/style.css` — стили
- `assets/vehicles/` — реальные растровые изображения
- `assets/silhouettes/` — SVG fallback

Если `cars.json` временно не загрузится, выбор автомобилей всё равно останется рабочим благодаря встроенному резервному набору данных.
