# AutoScale 4.3.4 Light

Лёгкая версия без локальных фотографий и папки assets.

## Главное изменение
Visual Scene Math Engine:
- боковая сцена: 5000 × 3000 мм;
- фронтальная сцена: 5000 × 3000 мм;
- оба ракурса используют одинаковую математическую сцену;
- режим «друг за другом»: две сцены по 5000 × 3000 мм;
- размеры автомобиля переводятся в пиксели по единому коэффициенту масштаба;
- все автомобили сравниваются внутри одной математической системы.

## Структура
autoscale-4.3.2-light/
├── index.html
└── README.md

Сайт получает автомобили с API:
https://autoscale-mvp.onrender.com/cars

Если API временно недоступен, включается встроенный fallback из 4 автомобилей.


## Постоянная сетка сцены
Сетка всегда активна и не имеет переключателя:
- размер одной ячейки: 500 мм;
- по горизонтали: 10 ячеек = 5000 мм;
- по вертикали: 6 ячеек = 3000 мм;
- одинаковая математическая система используется в боковом и фронтальном режимах.
