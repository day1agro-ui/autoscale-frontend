# AutoScale AI Visual Pack

В этой папке находятся растровые AI-визуализации автомобилей.

Текущий стандарт:
- отдельный файл для каждого автомобиля;
- side / front / top;
- единый студийный стиль;
- изображения используются только для визуализации;
- реальные размеры всегда берутся из `data/cars.json`.

Важно: при добавлении новых автомобилей желательно использовать PNG/WebP с прозрачным фоном и без текста.
